카드 직접 만들기 + 승인(PR) 페이지 — 사용법

■ 유저
  1) 상점 → 「🛠 카드 직접 만들기」 (100골드, 만드는 장수 제한 없음 · 승인 요청은 무료)
  2) 이름 · 코스트 · 공격력 · 체력 · 그림(선택)을 정하고, 탭(키워드/전투의 함성/죽음의 메아리/턴 시작·종료/반응/상시/단점)에서 효과를 체크
     - 기본으로는 쉬운 효과만 보이고, 「고급 효과까지」를 켜면 전부 보임 (총 186개). 검색창으로도 찾을 수 있음
     - 문장 속 숫자는 그 자리에서 바로 바꿀 수 있음 (예: 모든 캐릭터에게 피해를 [3▾] 줍니다). 숫자를 바꾸면 자동으로 체크됨
     - 「직접 디자인한 하수인 소환」(전투의 함성·죽음의 메아리·턴 종료 탭 맨 위): 소환수 이름·공격력·체력·키워드·그림·마릿수를 정함
       소환수도 「죽으면 / 내 턴이 끝날 때」 또 소환수를 부를 수 있음 (3단계까지). 예산 = 마릿수 × (공+체+키워드+소환수의 소환 비용) ÷ 2, 턴 종료 소환은 ×2
     - 예산 = 코스트 × 3.  공격력 + 체력 + 효과 비용(하 1 · 중 2 · 상 3)이 예산을 넘으면 만들 수 없음. 단점 효과는 예산 +1
     - ⚠ 경고가 붙은 효과도 고를 수는 있음 (예: 학사모 카드가 있어야 효과가 있어요)
  3) 만들면 그 카드 2장을 받음 → 덱 편집에 넣으면 AI 대전 · 모험에서 바로 사용
  4) 「승인 요청 보내기」 → 개발자가 승인하면 유저 대전에서도 사용 가능
  5) 고치기 (10골드, 이름은 고정): 「내가 만든 카드」에서 ✏️ 버튼
     - 만듦 카드: 고쳐도 「만듦」 그대로 → 승인 요청 전까지 유저 대전 불가
     - 반려 카드: 반려 사유가 위에 보이고, 저장하면 바로 다시 승인 요청(승인 대기)
     - 승인 대기·승인된 카드는 고칠 수 없음. 덱에 넣어 둔 카드는 저장하면 바로 새 버전으로 바뀜
     (승인 전 카드가 사용 중 덱에 있으면 유저 대전 매칭이 안 되고 안내 문구가 나옴)

■ 개발자 (서버 컴퓨터)
  1) 내 계정을 개발자로:  npm run make-admin 내아이디   → 다시 로그인
  2) 메인 화면 개발자 메뉴 「🛠 카드 승인 (PR)」 또는  http://localhost:3000/review.html
  3) 열린 요청을 눌러 카드 · 예산 내역 · 봇 대전 자동 점검 결과를 보고 「✓ 승인 (Merge)」 / 「✕ 반려」 (메모는 만든 사람에게 보임)
     - 15초마다 새 요청을 자동으로 불러옴
     - 고친 카드는 「🔀 바뀐 점」에서 이전 버전과 비교 (빨강 - 빠진 효과 / 초록 + 생긴 효과), 타임라인에 생성 → 반려 → 수정 → 재요청 흐름
  4) 골드 수정
     - 다른 유저: 승인 페이지 「💰 골드 관리」 탭 → 유저 검색 → 값 설정 / +100 · +1,000 · +10,000 · -1,000 (그 유저는 새로고침 필요)
     - 내 골드: 게임 메인 개발자 메뉴 「💰 내 골드 설정」 (게임 화면에 바로 반영)
     - 누가 누구의 골드를 바꿨는지 gold_log 표에 기록되고 골드 관리 탭에 최근 20건이 보임

■ 바꾸고 싶을 때
  - 가격(GOLD_COST) · 고치기 가격(EDIT_GOLD) · 한 사람당 장수(null=무제한) · 예산 배율 · 소환 단계:  public/js/cardrules.js 의 CUSTOM
  - 비속어 목록:                       public/js/cardrules.js 의 BANNED
  - 효과 목록은 기존 카드에서 자동으로 뽑음. 카드를 추가·수정했으면 다시 생성:
        node tools/build-effect-catalog.js     (효과마다 봇 대전으로 오류 검사 후 public/js/effectcatalog.js 를 새로 씀)

■ 바뀐 파일
  새 파일   server/customcards.js · public/js/{effectcatalog,cardrules,cardmaker,customboot}.js · public/css/cardmaker.css · public/review.html · tools/build-effect-catalog.js
  고친 파일 public/js/engine.js (전투의 함성 여러 개 · 카드 문장) · public/js/shop.js · public/js/progress.js (직접 만든 카드는 팩·제작에서 제외)
            public/js/ui.js (개발자 버튼) · public/index.html (상점 버튼 · 스크립트) · server/index.js · server/decks.js · server/pvp.js · server/pvp-db.js
  데이터는 data/game.db 의 custom_cards(카드·카드 그림) · custom_card_images(소환수 그림) · custom_card_versions(버전 기록) · gold_log(골드 변경 기록) 표에 저장됨
