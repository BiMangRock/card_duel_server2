업데이트 10 — 브라우저 팝업을 게임 안 창으로. my-server 폴더에 풀어 덮어쓰세요. (업데이트 9 기준)

  ※ 처음 받은 업데이트 10 파일은 ui.js 에 오타가 있어 메인 화면이 멈췄습니다(골드·덱 표시 사라짐, 클릭 안 됨). 이 파일로 다시 덮어쓰세요.

  - 브라우저 기본 창(alert·confirm)을 모두 없애고 게임 안 창으로 바꿈 → 창이 떠도 전체화면이 풀리지 않음
      입학할까요? · 자퇴할까요? · 재학 중 덱 변경 불가 · 입학 실패 · 모험 덱 저장 실패
      메뉴 둘러보기 그만두기 · 지난 판(리플레이) 알림
      보스 편집: 삭제 · 틀 맞추기 · 덱 규칙 오류 · 보스 목록 초기화
      로그인 화면: 회원가입 닉네임 확인
  - Enter = 확인, Esc 또는 바깥 클릭 = 취소. 되돌릴 수 없는 일(자퇴·삭제·초기화)은 빨간 창
  - 로그인할 때 브라우저의 「비밀번호를 저장할까요?」 창이 뜨지 않음
      비밀번호 칸을 점(●)으로 가린 일반 글자 칸으로 바꿈. 대신 브라우저에 저장해 둔 비밀번호 자동 입력도 안 됨
  - npm test 맨 앞에 화면 스크립트 문법 검사(server/test-syntax.js) 추가
