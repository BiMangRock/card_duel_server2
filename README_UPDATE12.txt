업데이트 12 — 기출 힌트를 「나」 대화창으로. my-server 폴더에 풀어 덮어쓰세요. (업데이트 11 기준)

  - 힌트가 있는 문제: 컷신처럼 파란 「나」 이름표가 붙은 대화창 + 오른쪽에 주인공 얼굴
      대사는 하늘색 괄호 혼잣말: (이건… 확신의 3번이다 …!) / (2번… 아니면 5번…?) / (신의 계시다… 1번 아니면 3번 …!)
      얼굴: 강한 확신 = 안도, 약한 확신 = 차분, 탐구 = 당황
      대사가 한 글자씩 다 나오면 보기 번호가 번쩍 (탐구 「아닌 것 같은데」는 그 두 개가 흐려짐)
  - 힌트 있는 문제는 문제지를 왼쪽 위로 좁혀서 얼굴·대화창과 안 겹치게. 세로 화면에서는 얼굴 숨김
  - 예전 「속마음」 막대는 없앰
