카드 제안(카드 PR) 기능 설치 — 시연용

1) 이 폴더 안의 파일을 my-server 폴더에 그대로 복사해 덮어씁니다.
     test-gemini.js          → my-server/
     server/cardai.js        → my-server/server/
     server/index.js         → my-server/server/   (아래 2줄이 추가된 버전. 이미 고친 index.js 가 있으면 덮어쓰지 말고 2줄만 직접 추가)
     public/cardai.html      → my-server/public/

   index.js 에 추가된 2줄
     (express.json({limit:'20kb'}) 줄 바로 위)  app.use('/api/cardai', express.json({ limit: '400kb' }));
     (맨 아래 404 처리 줄 바로 위)              app.use('/api', require('./cardai').router);

2) 키 확인 (서버 켜기 전에)
     PowerShell : $env:GEMINI_API_KEY="키값"; node test-gemini.js
     200 이면 성공 / 404 면 GEMINI_MODEL=모델이름 지정 / 429 면 잠시 뒤 다시

3) 카드 변환 시험
     node test-gemini.js card "낼 때 카드 2장을 뽑는다"
     node test-gemini.js card "두 플레이어의 덱을 서로 바꾼다"

4) 서버 실행
     PowerShell : $env:GEMINI_API_KEY="키값"; npm start
     브라우저에서  http://localhost:3000/cardai.html   (로그인 필요)

5) 개발자(승인) 화면
     npm run make-admin 으로 관리자 계정을 만든 뒤 같은 주소로 들어가면 아래쪽에 "개발자 검토"가 보입니다.
     승인된 카드는 data/approved-cards.json 에 쌓입니다. (게임 카드 목록·엔진에 넣는 건 아직 수동)

비상용: 키가 없거나 API 가 막히면  CARDAI_MOCK=1 npm start  → 미리 만든 답으로 같은 흐름을 시연할 수 있습니다.
        ("덱 … 바꾼다" 같은 문장은 새 효과 예시, 그 밖의 문장은 기존 효과 예시로 답합니다)

키는 코드나 GitHub 에 적지 마세요. 환경변수로만 넣습니다.
