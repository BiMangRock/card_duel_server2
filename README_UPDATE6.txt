1) 수능 보스 페이즈 (교시 전환) — 수능 보스만
  - 보스 체력이 66% · 33% · 15% 아래로 떨어질 때마다 한 번씩: 방어도 +5, 그리고 무작위로 하나를 얻음
      영웅 능력(일반 13종 · 보스 사용형 3종) 50% / 치트 50%. 치트는 비용 없는 지속 능력으로 영웅 능력 자리에 들어감
      먼저 얻은 치트는 영웅 능력 자리가 바뀌어도 계속 켜져 있음. 이미 켜진 치트 · 지금 영웅 능력과 같은 것은 안 뽑힘
      양쪽 규칙(너도? 나도? · 균일가 주문 · 피의 통행료)도 후보 → 걸리면 플레이어에게도 적용 (배너 · 전장 규칙 띠에 빨간색으로 표시)
      빠진 것: 게임 도중엔 효과가 없는 '시작할 때만' 치트(강인한 영웅 · 앞선 출발 · 풍부한 손패 · 선발대 · 방어도 시작 · 값싼 병력 · 속독),
               룬 치트 3종(수능 덱에 룬 카드 없음), 피로 면역(N수 선언과 겹침)
  - 한 번에 큰 피해로 선 두 개를 같이 넘으면 차례로 두 번
  - 66% → 2교시 수학 / 33% → 3교시 영어(OMR 밀림 포함) / 15% → 5교시 제2외국어(새 컷신, 브금이 혼테일로 바뀜)
    같은 입학(모험) 안에서 처음이면 그 교시 컷신 → 교시 배너, 이미 봤으면 교시 배너만
    배너 = 시험장 앞쪽 벽 그림 + 시계 바늘이 그 교시 시각으로 + 칠판 글씨 + 📢 방송 + 보스가 얻은 것
  - 수능 컷신(1교시)은 필적 확인란 → 1교시 국어(+쉬는 시간)까지만. 점심시간 · 수능 종료 장면은 뺐음
2) 고유 능력 「N수 선언」 (보스 편집 화면 → 고유 능력, 어느 보스에나 붙일 수 있음)
  - 덱이 비면 탈진 피해 대신, 카드를 뽑을 때마다 일반 카드 중 무작위 전설 · 특급 카드 1장 (손패가 가득이면 소각)
  - 수능 보스는 따로 저장한 적이 없으면 기본으로 켜져 있음 (편집 화면에서 '없음'으로 끌 수 있음)
  - 브리핑 · 상대 초상화 옆 특성 고리에 「고유 능력」으로 보임. 특성 도감에는 오르지 않음
3) 카드 첫 등장 연출 (한 판에 카드마다 한 번 — 다시 도전하면 또 나옴)
  - 아랍어 로또 괴물(5교시의 악령) · 물수능 컷 폭발 · OMR 카드 밀려쓰기. 누르면 넘어감
4) 엔딩 크레딧 — 수능 보스를 이길 때마다 (개발자 「보스 건너뛰기」 포함)
  - 승리 효과음 → 본령(딩동댕동 두 소절) + 📢 「수고하셨습니다. 문제지와 답안지를 제출하고 퇴실하세요.」
    → 화면이 회색으로 빠지며 청개구리 → S1~S5 장면당 6초 → Special Thanks → 「엄마, 아빠」에서 멈춤 → 곡을 줄이며 보상 화면 (약 50초)
  - 오른쪽 위 [건너뛰기]는 누구나 언제든 → 바로 보상 화면. 보상 묶음 고르기 창은 엔딩이 끝난 뒤에 뜸
5) 브금 — 수능 전야 슬리피우드 · 수능 날 아침 프렌즈스토리 · 필적 확인란/1교시/교시 컷신 세레니티 · 수능 보스전 파풀라투스 (5교시부터 혼테일)
